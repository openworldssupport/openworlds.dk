Programming Fundamentals

Programming is the act of telling a computer what to do using a language it can interpret or compile. A program is a set of instructions that turn input into output, process data, and respond to events.

What is code?

Source code is human-readable instructions written in a language that a compiler or interpreter understands.

Variables

Variables store values in memory so programs can reuse and change information during execution.

Data types

Integers, floats, strings, booleans, and more define the kind of data a variable can hold.

Functions

Functions isolate reusable logic and make programs easier to understand, test, and maintain.

Conditions

If statements decide what logic runs based on truth values and comparisons.

Loops

Loops repeat work until a condition changes, helping automate repeated tasks.

Variables, Values, and Memory

A variable is a named location in memory. The value stored there can be read, changed, and reused. For example:

age = 18
name = "Ada"
active = True

Here, age is a variable storing a number, name stores text, and active stores a boolean. The exact memory representation depends on the programming language and the machine architecture.

Why variables exist

Without variables, programs would have to hard-code values everywhere. Variables make logic flexible and reusable.

Common mistakes

  • Using a variable before assigning a value.
  • Mixing data types without understanding conversion rules.
  • Reusing names in ways that confuse scope.

Functions and Scope

def greet(name):
    return f"Hello, {name}!"

print(greet("OpenWorlds"))

Functions let developers package logic into reusable units. Sometimes the function takes input, sometimes it returns a value, and sometimes it does both. Scope determines where a variable can be accessed. A variable defined inside a function usually does not exist outside it.

Why this matters

Scope prevents accidental variable conflicts and helps keep code modular and predictable.

Async Programming

async function loadData() {
  const response = await fetch('/api/data');
  const data = await response.json();
  return data;
}

Async/await is a structured way to write code that waits for operations like network requests without blocking the whole page. The language can continue processing other work while the request finishes.

Big O Notation

Big O expresses how algorithm performance grows as input size increases. It helps compare structures and algorithms without relying on raw timing results from one machine.

  • O(1): constant time — access by index or direct lookup.
  • O(log n): logarithmic time — binary search.
  • O(n): linear time — scan a list once.
  • O(n log n): efficient sorting algorithms.
  • O(n²): nested loops and simple quadratic processes.
